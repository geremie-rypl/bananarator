# Bananarator

Campy iOS photo app: take a picture of a banana, decorate it with filters + 107 stickers across 10 packs, share it. SwiftUI, iOS 17+, Firebase, StoreKit 2.

## Repo layout

```
Bananarator/
  App/                  // entry point, AppState
  Features/             // Camera, Editor, Showcase, Store (MVVM)
  Models/               // FilterItem, StickerPack, BananaPost, UserProfile
  Services/             // Camera, Export, Firebase, StoreKit, Analytics
  Theme/                // palette, button/card styles, confetti backdrop
  Resources/
    Assets.xcassets/    // AppIcon, LaunchImage, Stickers/*.imageset
    Filters/, Stickers/ // folder references (legacy; stickers now live in Assets)

Bananarator.xcodeproj   // generated by xcodegen — do not hand-edit
project.yml             // xcodegen source of truth
Package.swift           // SPM (Firebase iOS SDK)

docs/
  firebase-setup.md             // console steps + paste-ready security rules
  plans/                        // approved design + feature plans

scripts/
  split_stickers.py             // alpha-island split of a multi-sticker sheet PNG
  build_sticker_assets.py       // turn split outputs into .imageset folders
```

## Building

Requires Xcode 15+ (full Xcode, not just CLT). First-time setup:

```sh
brew install xcodegen
xcodegen generate                     # rebuild Bananarator.xcodeproj
open Bananarator.xcodeproj
```

Build from CLI for iPhone 17 Pro simulator:

```sh
xcodebuild -project Bananarator.xcodeproj \
  -scheme Bananarator \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -configuration Debug build
```

Run on a real device: set `DEVELOPMENT_TEAM` in `project.yml` (or your team in Xcode → Signing & Capabilities) and rebuild.

## Adding stickers

1. Drop one transparent-PNG sheet per pack into `incoming/` (gitignored).
2. Split each sheet into individual sticker PNGs:
   ```sh
   python3 scripts/split_stickers.py incoming/04_pride.png incoming/split/pride \
     --prefix sticker_pride_ --no-merge
   ```
   Use `--no-merge` whenever stickers visually overlap in the source sheet (their alpha touches), so the splitter doesn't collapse two stickers into one bbox.
3. Regenerate the asset catalog so every split PNG becomes an `.imageset`:
   ```sh
   python3 scripts/build_sticker_assets.py
   ```
4. Add or extend the entry in `Bananarator/Models/StickerPack.swift` with the right `count`.
5. `xcodegen generate && xcodebuild …` to verify.

## Conventions

- **Plans live in `docs/plans/`**, dated `YYYY-MM-DD-slug.md`. Status header: Proposed / Approved / Implemented.
- **No CocoaPods** — Swift Package Manager only. Firebase comes in via SPM.
- **`xcodegen` is the source of truth** for the Xcode project. Don't edit `.pbxproj` by hand; edit `project.yml` and regenerate.
- **MVVM** with services in `Services/`. ViewModels own state, Views are declarative, Services hide framework calls (Firebase, Photos, StoreKit).
- **Theme tokens** in `Bananarator/Theme/BananaTheme.swift`. Don't hardcode colors in feature views — extend the palette and use a named token.
